NORTH/STORE - це сучасний вебдодаток інтернет-магазину, розроблений на платформі ASP.NET Core 10
та побудований за принципами Cloud-Native. Усі ключові компоненти системи інтегровані з хмарною інфраструктурою Amazon Web Services (AWS)
для забезпечення масштабованості, відмовостійкості та високої швидкості роботи.

Публічне посилання на проєкт: http://cloud-store2-env.eba-yehaert2.eu-central-1.elasticbeanstalk.com/

Використані сервіси:
• AWS Elastic Beanstalk - хостинг вебдодатку
• AWS RDS (PostgreSQL) - хмарна база даних. Використовується для збереження даних каталогу товарів, категорій та стану користувачів
• Amazon S3 - об'єктне сховище для збереження зображень товарів. Забезпечує безпечний доступ до медіафайлів за допомогою динамічної генерації тимчасових посилань
• Amazon SQS - хмарна черга повідомлень. Використовується для асинхронної обробки замовлень
• AWS IAM - управління доступами
